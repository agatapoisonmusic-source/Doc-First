== Сценарий

=== Валидация входящих параметров
Валидация параметров осуществляется следующим образом:
|===
| Параметр | Проверка | Действие при ошибке
| pinType | Не пустой, если передан pinValue | Возвращается ошибка 400 Bad Request
|===

=== Запрос данных сотрудника
При получении запроса бэк запрашивает данные по сотруднику.

|===
| Параметр запроса | Тип данных | Где | Передаваемый параметр запроса | Пример
| pinType | string | query | pinType | ABS_SAP
|===

=== Обработка ответа
Если данные о сотруднике найдены, метод возвращает их в неизменном виде.

Если данные не найдены, метод возвращает ошибку 404 Not Found.

=== Обработка ошибок
Возможные ошибки, которые могут возникнуть при выполнении метода:
|===
| Параметр | Условие ошибки | Детали ошибки
| pinType | Параметр передан, но отсутствует параметр pinValue | No pinValue for pinType
|===

=== Код ответа
|===
| Код | Описание | Примечание
| 200 | OK | Возвращается при успешном ответе.
|===
