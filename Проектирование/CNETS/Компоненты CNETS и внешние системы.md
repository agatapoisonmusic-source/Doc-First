# Компоненты CNETS и внешние системы

## Компоненты внутренние

### CNETS

- trade - БД MSSQL из поставки EFTR, содержит тонны таблиц, процедур и джобов, из которых задействованы очень немногие
- ITI_Integration - БД MSSQL, планировалась как вспомогательная БД интеграции EFTR и прочих систем компании, но переросла эту роль
- KeyCloak - хранилище учётных записей из поставки EFTR; CNETS использует его API
- keycloak_trade - БД MSSQL из поставки EFTR; на ней работает KeyCloak
- personal - БД MSSQL из поставки EFTR; служит для связи ID пользователей в KeyCloak и в БД trade
- RabbitMQ - из поставки EFTR; через него проходят торговые приказы; почти выпилен; осталось убрать из него сообщения отмены заявок
- Redis - в основном кэширует токены аутентификации для снижения нагрузки на KeyCloak
- CMS - Strapi; CNETS использует его API
- Kafka - помогает ослаблять зависимости внутри CNETS
- InfluxDB - хранит исторические рыночные данные ("свечи")
- MinIO - S3-совместимое хранилище

### не-CNETS

- ESB - шина данных для интеграции различных систем компании; первая версия вышла "не очень", сейчас активно разрабатывается вторая версия; её внутреннее устройство с т.зр. CNETS не имеет значения
- RMS - БД Oracle, центр торговой системы Matrix; служит домом и другим системам (ЭДО, пополнение с карт и СБП, и пр.)
- ODAS - БД Oracle, также принадлежит Матрице, хранит исторические рыночные данные ("свечи") и стоп-ордера
- ORDERS - БД Oracle, также принадлежит Матрице, хранит архив торговых заявок
- Streamers - gRPC-стримеры биржевых данных; принадлежат Матрице
- BO - БД Oracle, центр бэк-офиса; на критических участках CNETS ходит в неё непосредственно, в остальных случаях через ESB
- SmsService - сервис отправки конфиденциальных СМС (PIN-кодов и прочего)
- SimpleSign - сервис простой электронной подписи документов; компонент ЭДО
- CryptoKeys - сервис усиленной электронной подписи документов; компонент ЭДО
- FileStorage - файловая шара для хранения документов; компонент ЭДО
- EDO - API ЭДО
- Bitrix - используем его возможности по генерации pdf-документов, делимся с ним некоторыми данными
- QuikInstr - модуль неторговых поручений QUIK; для клиентов-пользователей ТС QUIK (т.е. не матричных) туда синхронизируется инфа по межпортфельным переводам
- Nabix - для СБП

## Компоненты внешние

- CBR - информ. ресурсы ЦБР; тащим справочник БИК
- RSB - банк Русский Стандарт; используем его API для пополнения брокерского счёта с банковской карты
- RuData - тащим некоторые данные по инструментам и эмитентам
- MOEX - ISS, тащим исторические рыночные данные, по которым обнаружились ошибка или нехватка в CNETS/ODAS
- NSPK - для СБП
